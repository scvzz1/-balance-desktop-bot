余额桌面挂件 · 公开发布版

环境：Windows 10/11，Python 3.10+（需 tkinter）。
启动：双击 start.bat，或运行 python bot.py。
浏览器绑定另需 Node.js 22+，以及默认 Chromium 系浏览器（Chrome/Edge等）。
首次在设置中填写自己的站点；example.com 仅为占位地址，不提供服务。

发布包不含真实账号、密码、API Key、Cookie、配置、截图、聊天记录或浏览器数据。
公开版使用独立的 BalanceDesktopBot 配置目录，不读取开发者版本配置。
凭证由 Windows 当前用户 DPAPI 加密保存；复制到其他用户或电脑需重新登录。
可选保留的专用浏览器环境包含登录状态，禁止提交到仓库。
不要从开发工作目录直接 git add .；请仅以本目录作为仓库根目录。

人物素材来自 AI 生成及本地加工，第三方模型/素材使用条款需自行核对；本包未擅自指定开源许可证。
