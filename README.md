# Balance Desktop Bot

一个适用于 Windows 的 AI API 中转站余额桌面挂件。

它会在桌面上显示当前账号的余额或额度，支持多个站点、多个账号和多种登录方式。挂件使用 Python 标准库 Tkinter 绘制，人物素材和动画资源已随项目提供。

## 功能

- 多账号、多站点管理
- API Key、账号密码、面板 Token
- 使用系统默认浏览器完成独立登录绑定
- sub2api、new-api / one-api 兼容接口自动识别
- 余额、额度、今日消耗、套餐状态显示
- 账号切换、全部账号余额总览
- 角色造型切换、眨眼、鼠标跟随和点击表情
- 连接诊断与脱敏复制
- 配置原子保存、Windows 当前用户 DPAPI 加密
- 单实例保护、请求超时、并行总览和旧请求隔离

## 运行环境

- Windows 10/11
- Python 3.10 或更高版本
- Python 安装时需要包含 Tkinter（Windows 官方安装包通常默认包含）
- 浏览器绑定功能额外需要 Node.js 22+，以及受支持的系统默认浏览器，例如 Chrome、Edge、Brave 或 Vivaldi

## 启动

双击：

```text
start.bat
```

也可以在命令行运行：

```text
python bot.py
```

首次启动后，在设置窗口中填写自己的站点地址和认证信息。`example.com` 只是占位示例，不提供余额服务。

## 认证方式

### API Key

适用于提供 OpenAI 兼容网关或 API Key 余额接口的站点。程序会自动尝试匹配接口类型。

### 账号密码

适用于站点提供标准面板登录接口的情况。密码由 Windows 当前用户 DPAPI 加密保存。

### 粘贴 Token

适用于登录态可以从面板开发者工具复制的情况。Token 过期后需要重新粘贴，除非站点同时提供可用的刷新令牌。

### 默认浏览器绑定

点击设置中的“用默认浏览器登录绑定”，程序会打开一个独立浏览器配置，不读取日常浏览器的个人配置。登录完成后，程序只接收目标站点同源的登录令牌或经过验证的 Cookie。

可选“保留此站点的专用登录环境”，用于减少重复登录。该目录可能包含登录状态，严禁提交到 Git 仓库。
